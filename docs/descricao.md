 Objetivo

O Pet Conect conecta pessoas e empresas a animais para fins de companhia, terapia e bem-estar.

 Tipos de cliente

- Pessoa física
- Empresas (hospitais, RH corporativo)

 Fluxo do sistema

1. Cliente se cadastra
2. Escolhe um pet
3. Realiza um aluguel
4. Efetua pagamento
5. Sistema registra logs
